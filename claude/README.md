# [claude](https://claude.com/)

## Download

- app-unavailable-in-region

```bash
# Windows powershell
irm https://claude.ai/install.ps1 | iex

# Linux / macOS
curl -fsSL https://claude.ai/install.sh | bash
```

- npm-deprecated

```bash
npm install -g @anthropic-ai/claude-code
```

## Run

```bash
claude
claude --version
```

```bash
ollama launch claude
```
